# 単語帳アプリ

## 1. 概要
学習する中で出てくるIT用語・技術スタック・略語などを自分専用に生理・暗記するためのWebアプリケーション。
既存のメモツールやスプレッドシート管理から脱却し、効率的なインプットと復習を行える環境を目指す。

## 2. 開発背景・目的
- **背景**: 業務の中でわからない単語が日々多く発生している
- **目的**:
  - 単語の記録・検索を効率化し、知識の定着を図る
  - CRUD機能の先にある本格的なJava Webアプリ開発（要件定義〜テスト）を一通り体験する。

## 3. 技術スタック（予定）
- **バックエンド**: Java (JDK 17 or 21) / Spring Boot
- **フロントエンド**: HTML5 / CSS3 / Thymeleaf
- **データベース**: PostgreSQL (開発用: H2 Database)
- **ビルドツール**: Gradle
- **バージョン管理**: Git / GitHub
