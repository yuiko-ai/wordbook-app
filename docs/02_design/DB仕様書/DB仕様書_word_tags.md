# word_tags(中間テーブル)

wordsとtagsテーブルの中間テーブル

## 概要
- 単語とタグの紐付け（多対多の関係）を管理する。

## テーブル定義
| 論理名 | 物理名 | データ型 | 制約 | デフォルト値 | 備考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 紐付けID | id | BIGSERIAL | PK | - | 自動採番 |
| 単語ID | word_id | BIGINT | FK, NOT NULL | - | `words.id` を参照 |
| タグID | tag_id | BIGINT | FK, NOT NULL | - | `tags.id` を参照 |

※ `word_id` と `tag_id` の組合せに **複合UNIQUE制約**（同じ単語に同じタグを複数登録できない制御）を設定する。

## リレーション
| リレーション種別 | 対象テーブル | 対象カラム | 備考 (条件など) |
| :--- | :--- | :--- | :--- |
| **Belongs To** (多対1) | `words` | `id` | どの単語に紐づくか（`word_id` で紐付け） |
| **Belongs To** (多対1) | `tags` | `id` | どのタグに紐づくか（`tag_id` で紐付け） |
