# API仕様書 - タグ管理機能

## 1. API一覧表
| No | 機能名 | メソッド | エンドポイント | 概要 |
| :--- | :--- | :--- | :--- | :--- |
| T-01 | タグ一覧取得 | GET | `/api/tags` | ログインユーザーのタグ一覧を取得する |
| T-02 | タグ新規登録 | POST | `/api/tags` | 新しいタグを登録する |
| T-03 | タグ情報更新 | PUT | `/api/tags/{id}` | 指定したIDのタグ情報を更新する |
| T-04 | タグ削除 | DELETE | `/api/tags/{id}` | 指定したIDのタグを削除する |


## 2. API詳細
### T-01: タグ一覧取得
- **概要**: 登録済みのタグリストを取得する
- **リクエスト(送信データ)**: 
  - なし
- **レスポンス(返却データ)**: 成功時（ステータスコード: 200） 
  ```json
  [
    {
        "id": 1,
        "name": "AWS",
    },
    {
        "id": 2,
        "name": "基本用語",
    },
  ]
  ```

### T-02: タグ新規登録
- **概要**: 新しいタグを登録する
- **リクエスト**: 
  ```json
  {
    "name": "java"
  }
  ```
- **レスポンス**: 成功時（ステータスコード: 201 Created）
  ```json
  {
    "id": 3,
    "name": "Java"
  }
  ```

### T-03: タグ情報更新
- **概要**: 既存のタグ名を更新する
- **リクエスト**:
  ```json
  {
    "name": "Java (Spring Boot)"
  }
  ```
- **レスポンス**: 成功時 (ステータスコード: 200 OK)
  ```json
  {
    "id": 3,
    "name": "Java (Spring Boot)"
  }

### T-04: タグ削除
- **概要**: 指定したタグを削除する
- **リクエスト**: なし（URLの `{id}` で対象を指定）
- **レスポンス**: 成功時 (ステータスコード: 204 No Content)
