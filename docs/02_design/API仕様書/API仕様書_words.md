# API仕様書 - 単語管理機能

## 1. API一覧表
| No | 機能名 | メソッド | エンドポイント | 概要 |
| :--- | :--- | :--- | :--- | :--- |
| W-01 | 単語一覧取得 | GET | `api/words` | ログインユーザーの単語一覧を取得する | 
| W-02 | 単語新規登録 | POST | `/api/words` | 新しい単語を登録する | 
| W-03 | 単語詳細取得 | GET | `api/words/{id}` | 指定したIDの単語の詳細情報を取得する |
| W=04 | 単語情報更新 | POSt | `api/words/{id}` | 指定したIDの単語の詳細情報を更新する | 
| W-05 | 単語削除 | DELETE | `/api/words/{id}` | 指定したIDの単語を削除する |


## 2. API詳細
### W-01: 単語一覧取得
- **概要**: 登録済みの単語リストを取得する
- **リクエスト(送信データ)**:
  - なし（画面を開く際にそのままアクセスするため）
- **レスポンス（返却データ）**: 成功時（ステータスコード: 200）
  ```json
  [
    {
        "id": 1,
        "term": "デプロイ",
        "meaning": "サーバーに配置して利用可能にすること",
        "importance": 5,
    },
    {
        "id": 2,
        "term": "トランザクション",
        "meaning": "分割できない一連の処理のまとまり",
        "importance": 4
    }
  ]
  ```
### W-02: 単語新規登録
- **概要**: 画面で入力した情報をもとに単語を登録する。
- **リクエスト（送信データ）**:
  ```json
    {
    "term": "新しい単語",
    "meaning": "単語の意味",
    "example": "例文があれば入力",
    "url": "[https://example.com](https://example.com)",
    "section_id": 1,
    "importance": 3,
    "tag_ids": [1, 2]
    }
    ```
- **レスポンス(返却データ)**: 成功時 (ステータスコード: 201 Created)
　```json
    {
    "id": 3,
    "term": "新しい単語",
    "meaning": "単語の意味"
    }
  ```

### W-03: 単語詳細取得
- **概要**: 選択した単語の詳細情報（タグやセクション情報含む）を取得する
- **リクエスト(送信データ)**:
  - なし(URLの`{id}`で対象を指定)
- **レスポンス**: 成功時（ステータスコード: 200 OK）
  ```json
  {
    "id": 1,
    "term": "デプロイ",
    "meaning": "サーバーに配置して利用可能にすること",
    "example": "本番環境へデプロイする",
    "url": "https://example.com/deploy",
    "importance": 5,
    "section": { "id": 1, "name": "インフラ", "color_code": "#FF5733" },
    "tags": [
      { "id": 1, "name": "AWS" },
      { "id": 2, "name": "基本用語" }
    ]
  }
  ```

### W-04: 単語詳細更新 
- **概要**: 既存の単語の情報を上書き更新する
- **リクエスト（送信データ）**:
  ```json
  {
    "term": "デプロイ (修正後)",
    "meaning": "意味を修正しました",
    "example": "修正した例文",
    "url": "https://example.com/updated",
    "section_id": 1,
    "importance": 4,
    "tag_ids": [1, 3]
  }
  ```
  - **レスポンス**: 成功時 (ステータスコード: 200 OK)
  ```json
  {
    "id": 1,
    "term": "デプロイ (修正後)",
    "meaning": "意味を修正しました"
  }
  ```

### W-05: 単語削除
- **概要**: 指定した単語をデータベースから削除（物理削除）する
- **リクエスト**: なし（URLの `{id}` で対象を指定）
- **レスポンス**: 成功時 (ステータスコード: 204 No Content)
  - ※削除成功時はデータを返す必要がないため、空のレスポンスを返す。
