# API仕様書 - セクション管理機能

## 1. API一覧表
| No | 機能名 | メソッド | エンドポイント | 概要 |
| :--- | :--- | :--- | :--- | :--- |
| S-01 | セクション一覧取得 | GET | `/api/sections` | ログインユーザーのセクション一覧を取得する | 
| S-02 | セクション新規登録 | POST | `/api/sections` | 新しいセクションを登録する |
| S-03 | セクション情報更新 | PUT | `/api/sections` | セクション情報を更新する | 
| S-04 | セクション削除 | DELETE | `/api/sections/{id}` | 指定したIDのセクションを削除する |


## 2. API詳細
### S-01: セクション一覧取得
- **概要**: 登録済みのセクションのリストを取得する
- **リクエスト(送信データ)**:
  - なし
- **レスポンス（返却データ）**: 成功時（ステータスコード: 200）
  ```json
  [
    {
      "id": 1,
      "name": "Java",
      "color_code": "#FF5733"
    },
    {
      "id": 2,
      "name": "DB設計",
      "color_code": "#33C4FF"
    }
  ]
  ```

### S-02: セクション新規登録
- **概要**: 画面で入力した情報をもとにセクションを登録する
- **ビジネスルール**: 
  - `name`は必須入力で最大文字数50文字
  - 同一ユーザー内で同じセクション名`name`、カラーコード`color_code`を重複登録することは不可
  - `color_code`は`#`から始まる7桁のカラーコード形式のみ許可
- **リクエスト(送信データ)**:
  ```json
  {
    "name": "フロントエンド",
    "color_code": "#42b883"
  }
  ```
- **レスポンス（返却データ）**: 成功時（ステータスコード: 200）
  ```json
  {
    "id": 3,
    "name": "フロントエンド",
    "color_code": "#42b883"
  }
  ```

### S-03: セクション情報更新
- **概要**: 既存のセクション名やカラーコードを更新する
- **ビジネスルール**:
  - 既に登録済みのセクション名`name`、カラーコード`color_code`では更新不可
  -  `color_code`は`#`から始まる7桁のカラーコード形式のみ許可
- **リクエスト(送信データ)**:
  ```json
  {
    "name": "フロントエンド(new)",
    "color": "#35495e",
  }
  ```

### S-04: セクション削除
- **概要**: 指定したセクションを削除する
- **ビジネスルール**: 
  - 単語が1件以上紐付いているセクションは削除不可とする
- **リクエスト**: なし（URLの `{id}` で対象を指定）
- **レスポンス**: 成功時 (ステータスコード: 204 No Content)
