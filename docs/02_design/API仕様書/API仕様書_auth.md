# API仕様書 - ユーザー認証・管理機能

## 1. API一覧表
| No | 機能名 | メソッド | エンドポイント | 概要 |
| :--- | :--- | :--- | :--- | :--- |
| U-01 | ユーザー新規登録 | POST | `api/auth/register` | 新しいユーザーアカウントを作成する |
| U-02 | ログイン | POST | `api/auth/login` | 認証を行う |
| U-03 | ユーザー情報取得 | GET | `/api/auth/me` | 現在ログインしている自分の情報を取得する | 

## 2. API詳細
### U-01: ユーザー新規登録
- **概要**: 画面で入力した情報(名前、メールアドレス、パスワード)をもとにユーザーを登録する。
- **リクエスト(送信)**:
  ```json
  {
    "name": "山田太郎",
    "email": "test@example.jp",
    "password": "test"
  }
  ```
- **レスポンス(返却データ)**: 成功時（ステータスコード: 201 Created）
  - ※登録完了後はそのままログイン画面に遷移するため、特にデータは返さない（空でOK）。

### U-02 ログイン
- **概要**: メールアドレスとパスワードで認証を行う。
- **リクエスト(送信)**:
  ```json
  {
    "email": "test@example.jp",
    "password": "test"
  }
  ```
- **レスポンス(返却データ)**: 成功時（ステータスコード: 200 OK）
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
  ```

### U-03 ユーザー情報取得
- **概要**: 現在のログインユーザーの基本情報を取得する。
- **リクエスト(送信)**: なし（※裏側でログイン時のトークンを送信して判定する）
  - 成功時（ステータスコード: 200 OK）
  ```json
  "id": 1,
  "name": "山田太郎",
  "email": "test@example.jp"
  ```
