# 要件定義

## 1. システム概要・目的
- **概要**: 日々の業務や学習で出会うIT用語を効率的に記録・分類・検索・暗記するためのWebアプリケーション
- **目的**: 
  - Googleドキュメントやスプレッドシート管理での「検索のしづらさ」「カテゴリ分類のしづらさ」を解消する
  - 要件定義からテストまでのWebアプリ開発一連の工程を経験し、Java / Spring Boot / PostgreSQL の知見を深める。
  
## 2. ターゲットユーザー・利用シーン
- **ターゲット**: 自分自身
- **利用シーン**: 
  - 業務中や学習中に分からない単語が出た際、即座に登録・検索する。
  - 過去に調べた単語の定義や関連URLを後からサッと検索・参照する

## 3. 機能要件

### 3.1 単語帳メイン機能（MVP）
まずは開発の核となるCRUD機能と検索を実装する。
| No | 機能名 | 機能概要 |
| :--- | :--- | :--- |
| F-01 | 単語一覧表示 | 登録済みの単語を一覧形式で表示する（ページネーション対応） |
| F-02 | 単語新規登録 | 単語名、意味、例文・利用シーン・参考URL、セクション、重要度、タグを入力して保存する |
| F-03 | 単語詳細表示 | 単語の情報を確認する |
| F-04 | 単語編集 | 既存の単語情報を修正する |
| F-05 | 単語削除 | 登録済みの単語を削除する |
| F-06 | 単語検索・絞り込み | 単語名での部分一致検索、セクションおよびタグによる絞り込みを行う |
| F-07 | セクション振り分け | 独自のセクションやタグを新規作成・編集・削除する。 | |

### 3.2. ユーザー認証・アカウント管理機能
※Spring Securityの学習を兼ねて実装する。

| No | 機能名 | 機能概要 |
| :--- | :--- | :--- |
| F-08 | ユーザー新規登録 | メールアドレス、パスワード、ユーザー名を入力してアカウントを作成する。 |
| F-09 | ログイン | メールアドレスとパスワードでシステムにログインする。 |
| F-10 | ログアウト | システムからログアウトし、ログイン画面に遷移する。 |
| F-11 | パスワード再設定 | パスワードを忘れた際、再設定用のリンク発行または再設定を行う。 |
| F-12 | パスワード変更 | ログイン状態から現在のパスワードと新しいパスワードを入力して変更sする。 |
| F-13 | アカウント情報更新 | ユーザー名やメールアドレスなどの登録情報を変更する。 |
| F-14 | アカウント削除 | アカウントおよび紐づくすべての単語データを削除（退会処理）する。 |

### 3.3 将来的な拡張機能
- ランダムクイズ機能（暗記カード形式）
- CSV形式での一括インポート/エクスポート
  

## 4. 非機能要件
- **動作環境**: PCブラウザ（Google Chrome 最新版）
- - **セキュリティ**: 
  - パスワードはハッシュ化（BCrypt等）してデータベースに保存する
  - 未ログイン状態での保護されたページへのアクセスを遮断する
